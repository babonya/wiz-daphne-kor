# Wizardry Daphne Dungeon Macro Script (Antigravity Bot)

> **WizDapKor_v1.16.0 안내**
> - 상자 개봉 시 우하단 대화 화살표(`dialogue_indicator.png`)를 범용적으로 검출하여 아이템 정산창을 넘기는 메커니즘이 완성되었습니다.
> - 상자공포 상태이상 캐릭터 선택 시 나타나는 예외 대화 팝업("열 수 없다")을 감지해 안전지대 터치로 닫고 캐릭터 선택창으로 복귀하는 자가 복구 루프가 안전하게 탑재되었습니다.

본 스크립트는 모바일 게임 '위저드리 다프네'의 던전 루프 파밍을 자동화하기 위한 파이썬 기반의 이미지 매칭 매크로 솔루션입니다.

---

## 🌟 핵심 기능
1. **자동 던전 주회 및 회군**: 백아에서 지정된 횟수만큼 던전 주회 후, 자동으로 마을로 복귀하여 여관 숙박 정비(레벨업/부활/체력 회복)를 수행합니다. (추후 타 던전 확장 예정)
2. **전투 후 자동 정비 (정교한 힐링)**: 지정된 전투 횟수 누적 시 혹은 상자 개봉 정산 종료 직후, 파티원 체력을 진단하여 자동으로 힐러를 소환해 파티 치료를 수행합니다.
3. **2중 자가 복구 가드 (Self-Healing)**:
   - 앱/에뮬레이터 프리징 시 프로세스를 강제 종료하고 콜드 리부트(Cold Boot)를 수행합니다.
   - 재기동 시 인게임 점검, 다운로드, 네트워크 오류, 주의 경고창, 기동 공지 팝업을 무인으로 자동 돌파하여 다시 정상 순회로 이행합니다.

> [!WARNING]
> **던전 작동 범위 제한**
> - 현재 릴리즈는 **"백아의 동굴 지하 1층"** 구역의 순회 및 마을 회군에 완벽히 최적화되어 있습니다.
> - 아군이 전멸하거나 주인공이 사망할 경우 부활 연차 탭핑이 가동되나, 개인 전투력 및 파티 셋팅에 따라 안전한 스펙에서 주행하시는 것을 강력히 권장합니다.

## ⚙️ 1. 에뮬레이터 (MuMu Player) 및 게임 내 설정

> [!IMPORTANT]
> **MuMu Player의 기본 표준 세팅을 변경 없이 그대로 유지해야 합니다.**
> - 매크로의 이미지 템플릿 및 ROI 박스 검출 기준은 **MuMu Player 12의 기본 표준 해상도인 `2560 x 1440` (360 DPI)**을 기준으로 제작되었습니다.
> - 해상도를 임의로 변경할 경우 이미지 매칭 스캔 영역이 찌그러지거나 좌표가 왜곡되어 오탐/오클릭을 격발하게 됩니다.

### 에뮬레이터 설정
* **디버그 모드 (ADB) 활성화**: 
  - MuMu 플레이어 설정에서 디버깅 모드(ADB)를 항상 허용으로 설정해 주셔야 파이썬이 통신할 수 있습니다.
  - 기본 접속 포트는 통상 `16384` (MuMu 12 기본값)이며, 스크립트 실행 시 3중 포트 자동 스위칭 레이더가 활성화되어 연결을 수립합니다.

### 위저드리 다프네 게임 내 설정
1. **미니맵 배율 기본값 고수**:
   - 던전 내 미니맵과 화면 상태는 반드시 **게임 초기 상태(기본 줌 세팅)** 그대로 유지해야 합니다.
   - 사용자가 인위적으로 미니맵을 줌인(확대) 또는 줌아웃(축소)한 상태일 경우, 맵의 크기나 비율이 달라져 매크로의 이동 제어 및 매칭 엔진이 정상 작동하지 않습니다.
2. **인게임 [설정] (톱니바퀴) 권장 세팅**:
   | 설정 항목 | 권장 세팅값 | 비고 |
   | :--- | :--- | :--- |
   | **화질 설정** | `속도우선` | 프레임 드롭에 의한 탭 씹힘 방지 |
   | **프레임 제한** | `30fps` | CPU 리소스 절약 및 안정적 매칭 |
   | **자동선택** | `OFF` | 대열 꼬임 예방 |
   | **텍스트 일괄 표시** | `ON` | 대화창 연타 돌파 속도 극대화 |
   | **밝기 설정** | `최소` | 이미지 템플릿 색감 매칭의 무결함 유지 |

## 💻 2. 파이썬 환경 구축 및 필수 라이브러리 설치

- 설치 시 반드시 **[Add python.exe to PATH]** 옵션을 체크하여 환경 변수에 등록해 주세요.

윈도우 명령 프롬프트(cmd) 또는 PowerShell을 열고 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
```bash
pip install opencv-python pillow numpy pure-python-adb
```

## 🛠️ 3. `main.py` 사용자 환경 변수 커스텀 설정

`src/main.py` 최상단 **[글로벌 제어 세팅 변수 구역]**의 설정들을 본인의 계정 환경에 맞춰 변경해 사용할 수 있습니다.

| 변수명 | 기본값 | 상세 설명 |
| :--- | :---: | :--- |
| **`LIMIT_DUNGEON_LOOPS`** | `2` | 던전을 몇 바퀴 주회하고 마을(여관)로 회군하여 정비 및 숙박을 수행할지 설정합니다. |
| **`START_RUN_COUNT_OFFSET`** | `2` | 최초 실행 시 시작할 오프셋 카운트입니다. (마을 회군 테스트 시 `LIMIT_DUNGEON_LOOPS`와 같게 세팅하면 즉시 작동합니다.) |
| **`ENABLE_FIRST_COMBAT_SKILL`** | `0` | 첫 전투 시 숏컷 기반 광역 스킬 예약을 사용할지 설정합니다. (⚠️현재 미구현으로 무조건 `0` 고정) |
| **`ENABLE_HEAL_AFTER_CHEST`** | `1` | 상자 개방 성공 후 긴급 파티 치료(정비)를 작동할지 설정합니다. (`0`: Off / `1`: On) |
| **`HEALING_LOOPS`** | `1` | 몇 회의 전투마다 파티 힐링 정비를 수행할지 설정합니다.<br>- `1`: 매 전투 종료 시 필드 복귀 직후 즉시 힐링 실행<br>- `2`: 2회 전투 치를 때마다 힐링 실행<br>- `0`: 자동 힐링 정비 비활성화 |
| **`DUNGEON_FLOOR`** | `1` | 진입할 던전 층수를 지정합니다. (`1`: 지하 1층 진입 / `2`: 지하 2층 진입) |
| **`HEALER_SLOT`** | `5` | 1번~6번 슬롯 중 주 힐러(스켈톤 등)의 배치 슬롯 번호입니다. |
| **`MASKED_ADVENTURER_SLOT`** | `4` | 1번~6번 슬롯 중 주인공 캐릭터의 배치 슬롯 번호입니다. |
| **`CHEST_OPENER_SLOT`** | `6` | 1번~6번 슬롯 중 상자 따기(함정 해제)를 담당할 캐릭터 슬롯 번호입니다. |
| **`ENABLE_EMULATOR_REBOOT`** | `True` | 디바이스 오프라인 또는 5분간 정체 지속 시 에뮬레이터를 강제 재시작할지 설정합니다. |
| **`MUMU_EXECUTABLE_PATH`** | *(경로)* | 에뮬레이터 자동 재부팅을 위해 본인 PC 환경에 맞는 MuMu Player의 실행 파일(`nx_main\MuMuNxMain.exe`) 절대 경로를 입력합니다. |
| **`MUMU_VM_INDEX`** | `"0"` | 자동 재부팅할 MuMu 가상머신의 인덱스 번호를 지정합니다. (기본값 `"0"`) |

## 💀 4. 상자공포 상태이상 템플릿 등록 방법 (중요)

지정된 따개 캐릭터가 "상자 공포" 디버프에 걸렸을 때, 매크로가 이를 자동 감지하고 주인공(또는 다른 캐릭터)으로 우회하여 안전하게 함정을 해제하기 위해 보라색 해골 아이콘 템플릿을 등록해 두어야 합니다.

1. **상자공포(chestfear) 아이콘 캡처**:
   - 캐릭터 선택창에서 카드 내 캐릭터 이름 오른쪽에 작게 표시되는 보라색 해골 모양의 상태이상 아이콘을 정밀 캡처합니다.
   - 반드시 MuMu Player의 스크린샷 기능(`F9`)으로 전체 화면을 확보한 뒤, 상태이상 아이콘 영역을 정확히 크롭하여 `templates/chestfear.png` 경로에 저장해 주세요.
   - 이미 템플릿이 제공된 경우에는 변경 없이 그대로 사용하실 수 있습니다.

## 🚀 5. 매크로 실행 및 관리

### 실행 방법
1. MuMu 플레이어로 게임을 켜고 던전 필드 내에 캐릭터를 위치시킵니다.
2. 배포판 폴더에 동봉된 `Daphne Antigravity.bat` 배치 파일을 더블클릭하면 자동으로 에뮬레이터를 찾아 통신을 연결하고 주행을 개시합니다.

### 로그 관리
* **자동 디스크 청소기**:
  - 매크로를 실행하면 `logs/` 디렉토리에 실행 이력에 대한 상세 텍스트 로그 파일이 생성되고 백업됩니다.
  - 디스크 공간 절약을 위해 매크로 기동 시 **4일이 경과한 오래된 로그 및 이미지 파일들은 자동으로 영구 삭제** 처리됩니다.

### 에러 발생 시 대처법
- 매크로 오작동 또는 에러가 발생하여 멈추는 경우, 에러가 발생한 당시의 에뮬레이터 화면을 캡처하고, `logs` 폴더의 최신 로그 텍스트 파일 내용을 함께 첨부하여 Gemini의 Antigravity 에이전트에 문의하시면 개인 환경에 맞게 수정을 지원받으실 수 있습니다.

# village_common 템플릿 사용 가이드

이 폴더의 도장들은 `src/main.py`(마을 상태 판별)와 `src/inn_manager.py`(숙박 종료 판정)에 실제로 연동되어 있습니다 (1.17.0-hotfix1부터).
아래 표는 `cv2.matchTemplate`을 `load_template`/`load_grayscale_template`과 동일한 방식으로 재현하여
`dev/ROI_check/`의 여러 마을 실제 스크린샷과 대조한 실측 결과입니다.

## 도장별 권장 로더 & 임계값

| 파일 | 용도 | 권장 로더 | 권장 임계값 | 비고 |
|---|---|---|---|---|
| `temple.png` | "사원" 텍스트 (마을 상태 판별용 후보) | `load_grayscale_template` | 0.65 | 노던할로우 0.996, 루크나리아 0.855 |
| `inn.png` | "여관" 텍스트 (마을 진입 버튼용) | `load_grayscale_template` | 0.65 | 노던할로우 0.946, 루크나리아(닫힘/열림) 0.997 |
| `guild.png` | "모험가 길드" 텍스트 | `load_grayscale_template` | 0.65 | **노던할로우는 이벤트 마을이라 길드 자체가 없음 → 0.370, 미검출 정상** |
| `go_outside.png` | "마을 외곽" 텍스트 (던전행 버튼) | `load_grayscale_template` | 0.75 | 구아르다 0.927, 그랜드레기온 0.840, 루크나리아 0.924 / **노던할로우는 마을외곽 자체가 없음 → 0.358, 미검출 정상** |
| `char_down.png` | 캐릭터창 펼침 상태에서 접기 버튼 | `load_template` (이진화 160) | 0.65 | 노던할로우/이스벨크/구아르다/그랜드래기온 4개 마을 0.700~0.790으로 이진화가 그레이스케일보다 더 안정적 (예외 케이스). 단, worldmap_icon과 같은 야간배경 오탐 가능성이 이론상 있어 추후 증상 발견 시 재검토 대상. |
| `worldmap_icon.png` (구 `worldmap_isbelg.png`) | 마을→월드맵 나가기 아이콘 | `load_grayscale_template` | 0.80 | 5개 마을(주간) 0.889~0.995. **이진화(160)는 폐기** — 야간 배경(노던할로우 밤 장면)에서 왼쪽 위 검은 하늘 영역과 우연히 완벽 일치(1.000 @ 좌표 0,0)해 엉뚱한 곳을 클릭하는 실사용 버그가 확인됨(1.17.0-hotfix1에서 발견 및 수정). 아이콘만 타이트하게 크롭(투명화 편집 금지)한 건 계속 유효.

**공통 원칙**: 이 세트는 반투명 배경임에도 대부분 그레이스케일이 이진화보다 마을별 조명/색감 차이에 더 안정적입니다
(AGENTS.md의 "반투명=이진화 기본 원칙"과 다른 실측 결과이니, 이 표를 우선 따르면 됩니다).
`char_down.png` 하나만 예외적으로 이진화가 더 낫다고 검증됐지만(주간 스샷 기준), `worldmap_icon.png` 사례처럼 야간 배경에서 오탐 가능성을 배제할 수 없으니 실사용 중 이상 징후 있으면 그레이스케일 재검증 권장.

## 마을별 예외 (이벤트 마을 특성)

| 마을 | 길드 | 마을외곽 |
|---|---|---|
| 이스벨크 / 루크나리아 / 구아르다 / 그랜드레기온 | 있음 | 있음 |
| 노던할로우 (FFXI 이벤트 마을) | **없음** | **없음** (던전이 월드맵 직행형이라 마을 경유 불필요) |

## 코드 연동 현황

- `inn.png`(그레이스케일): "마을에 있다" 상태 판별 앵커 + 여관 진입 클릭 겸용으로 확정 연동됨. 마을별 개별 앵커(`Vill_Isbelg/village_anchor.png`, `FFXI/!!vill_FFXI.png` 등)는 전부 대체됨.
- `char_down.png`, `worldmap_icon.png`: 마을 이탈(월드맵으로 나가기) 시퀀스에 연동됨. `worldmap_icon.png`은 캐릭터창이 펼쳐져 있으면 가려지므로 앵커로는 쓰지 않고 클릭 전용으로만 사용.
- `temple.png`, `guild.png`, `go_outside.png`: 아직 코드 미연동. `go_outside.png`는 마을경유형 던전을 처음 추가할 때 같이 연동 예정 (프리셋 2개가 전부 월드맵 직행형이라 아직 실사용 검증 대상이 없음). `temple.png`/`guild.png`는 현재 별도 용도 없음.
